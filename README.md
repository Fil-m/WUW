# Кіноразом 🎬

Дивимось YouTube разом з друзями в реальному часі. Без реєстрацій, без бекенду, безкоштовно.

## Як користуватись

1. Відкрий [сторінку](https://fil-m.github.io/WUW/) — ти стаєш **хостом** кімнати.
2. Натисни **🔗 Лінк** і скинь його друзям (лінк містить код кімнати `#room=XXXXX`).
3. Друзі відкривають лінк, вводять ім'я — і бачать твою кімнату.
4. Встав посилання на YouTube-відео → **▶ Дивитись зараз**. Всі дивляться синхронно.
5. Пауза, перемотування, черга, чат, реакції — синхронізуються у всіх.

## Що вміє

- 🎥 Синхронний перегляд: **YouTube** (плей/пауза/перемотування + авто-вирівнювання відставання) **і прямі відео-файли** (.mp4 / .webm / .m3u8)
- 🔎 **Пошук фільмів** — кнопка «Фільми»: безкоштовні фільми з Internet Archive (прямі mp4, безкоштовно і легально)
- 💬 Чат у кімнаті
- 🎞 Черга відео (кожен може додати; коли відео закінчується — автоматично грає наступне)
- 😂 Реакції-емодзі поверх відео
- 👥 Список учасників
- 🔗 Кімната по лінку (без акаунтів)

## Як це працює

- **PeerJS (WebRTC)** — хост роздає стан відео учасникам напряму (mesh), без сервера. Хто створив кімнату — той хост.
- **YouTube IFrame API** — плеєр у кожного; хост є «годинником», гості підрівнюються під нього (дрейф >1.5с → перемотування).
- Один `index.html` — статика, яку можна хостити де завгодно.

## Обмеження (чесно)

- **Хост має бути онлайн** — коли хост закриває вкладку, кімната закривається (гості, які перезавантажать сторінку, можуть перехопити роль хоста).
- Працює через WebRTC — у рідкісних мережах (строгі NAT/фаєрволи) з'єднання може не пробитись; PeerJS має fallback через свій публічний TURN.
- Відео-файли (.mp4/.m3u8) мають бути **прямими посиланнями** на файл. Сайти з антибот-захистом (zfilm, lordfilm тощо) не віддають такі лінки напряму — їх треба витягувати через DevTools (Network → Media), і вони часто прив'язані до сесії/IP.
- Гостям іноді треба один раз клікнути «play», якщо браузер блокує автозапуск зі звуком (тоді відео грає приглушено, клік вмикає звук).

## Локальний запуск

```bash
python3 -m http.server 8000
# відкрий http://localhost:8000
```

## Технології

- [PeerJS](https://peerjs.com/) 1.5.4 (CDN)
- [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)
- Чистий HTML/CSS/JS, без збірки
